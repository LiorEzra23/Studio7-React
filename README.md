# STUDIO 7 — אתר לאלישבע, אדריכלות ועיצוב פנים

אתר תדמית רספונסיבי בעברית (RTL) ב־React/Vite, המבוסס על הלוגו, צילומי השיפוץ וההדמיות שהועלו לשיחה.

## הפעלה מקומית

1. חלצו את הקובץ `Studio7-React-Elisheva.zip`.
2. פתחו מסוף בתיקיית הפרויקט.
3. הריצו:

```bash
npm install
npm run dev
```

ניתן ליצור גרסה לפרסום בעזרת `npm run build` לאחר התקנת התלויות.

## תוכן מאושר על ידי בעלת הסטודיו

- **אלישבע**: בוגרת תואר B.Arch באדריכלות מאוניברסיטת אריאל.
- עבדה במשך ארבע שנים במשרדו של רון פליישר, וצברה ניסיון מתכנון ערים ועד עיצוב פנים.
- מתמקדת כיום בתכנון ועיצוב פנים לפרויקטים פרטיים, מסחריים וציבוריים.
- שירותים: תכנון ועיצוב פנים, הפקת תכניות עבודה, ליווי ביצוע.
- **פרויקט בתהליך:** שיפוץ יסודי ועיצוב פנים לדירת דופלקס בבני ברק — כל ארבע ההדמיות שייכות לפרויקט זה.
- **פרויקט שבוצע:** שיפוץ חדר הרחצה, השירותים וחדר הכביסה — בגלריית תמונות וסרטון נפרדים.

## חומרים ותצוגה מקדימה

כל התמונות, הסרטון והלוגו נמצאים תחת `public/assets/` ומקורם בחומרים שסופקו.

בקובץ ZIP נפרד נכללת תצוגה מקדימה עצמאית עם כל המדיה מוטמעת בקובץ HTML, ללא צורך בהרצת React. פתחו אותה ב־Chrome **לאחר חילוץ ZIP**. גם בגרסה זו הטופס נפתח באפליקציית האימייל.

האתר אינו כולל כתובת משרד, תעודת רישום אדריכלית, פרסי אדריכלות, חוות דעת או מספר פרויקטים שלא נמסרו. הניסוחים השיווקיים סביב אופן העבודה הם הצעות עריכה. מומלץ לאשר אותם לפני העלאת האתר לאוויר.
